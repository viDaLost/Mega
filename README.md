# Мега Червь — Web / iOS PWA / Telegram Mini App

Русскоязычный веб-порт старой Unity-аркады про гигантского подземного червя. Проект работает как статическое HTML5 Canvas-приложение и не требует отдельного сервера приложений.

## Возможности

- русский интерфейс;
- сенсорное управление для iPhone/iPad;
- PWA: установка на экран «Домой» через Safari;
- Telegram Mini App: подключён Telegram WebApp SDK;
- адаптивный Canvas и safe-area для iPhone;
- офлайн-кэш через Service Worker;
- автоматический деплой GitHub Actions → GitHub Pages;
- оригинальные Unity-ресурсы, игровые параметры и таблицы уровней восстановлены непосредственно из APK версии 2.0.0.

## Что восстановлено из полного APK

В качестве основного источника используется `Super_Mega_Worm_2.0.0_Android_2.3(1).apk`. Это полноценная Unity 4.3.4f1-сборка: в ней читаются `Assembly-CSharp.dll`, `mainData`, `level0`, `sharedassets0.assets`, `sharedassets1.assets` и resource streams.

Из `Assembly-CSharp.dll` восстановлены реальные классы игры, включая `SMW_Player`, `SMW_Spawner`, `SMW_ActorBase`, `SMW_DataManager`, `SMW_HUDManager` и код, связанный с боссами, EMP, ракетами, техникой и способностями.

Из `SMW_Spawner` восстановлена оригинальная `Standard_Adventure`: 26 уровней с реальными `GrowthRequired` и составом противников/объектов по каждому уровню. Эти данные лежат в `assets/original-levels.js` и уже используются веб-игрой.

Восстановлены оригинальные текстуры Воджиры, земли, классического фона, HUD, эффектов, транспорта, боссов, экранов обучения и других элементов. Для веб-рендера также подготовлены lossless-спрайты классической техники.

Подробный технический отчёт: [`RECOVERY.md`](RECOVERY.md).

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## GitHub Pages

GitHub Pages уже настроен. Workflow `.github/workflows/deploy-pages.yml` запускается на каждый push в `main` и автоматически публикует новую сборку.

Публичный адрес проекта:

`https://vidalost.github.io/Mega/`

## Telegram Mini App

В BotFather укажите HTTPS-адрес GitHub Pages как URL Mini App / Menu Button:

`https://vidalost.github.io/Mega/`

Приложение автоматически определяет Telegram WebView и вызывает `ready()` / `expand()`.

## iOS

Откройте опубликованный URL в Safari → «Поделиться» → «На экран Домой». PWA запускается как отдельное полноэкранное приложение и учитывает safe-area iPhone.

## Текущее состояние восстановления

Уже перенесены реальные параметры движения `SMW_Player`, 26 уровней основной кампании, оригинальная графика Воджиры/фона/земли, классическая техника, базовая логика боссов, EMP, огненного плевка и удара о землю.

Часть оригинальных WAV-аудиоклипов из APK успешно проверена и декодируется. Несколько ресурсов, экспортированных как `.mp3`, оказались Unity/ID3-обёртками без корректных MPEG-фреймов и поэтому пока не подключены. Для нескольких поздних boss-atlas файлов веб-порт временно использует проверенный fallback, пока их бинарная передача в репозиторий не будет подтверждена побайтно.
