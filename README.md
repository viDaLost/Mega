# Мега Червь — Web / iOS PWA / Telegram Mini App

Русскоязычная веб-адаптация аркады про гигантского подземного червя. Проект сделан как статическое HTML5 Canvas-приложение, поэтому запускается без сервера приложений.

## Возможности
- русский интерфейс;
- сенсорное управление для iPhone/iPad;
- PWA: можно добавить на экран «Домой» в Safari;
- Telegram Mini App: подключён Telegram WebApp SDK;
- адаптивный Canvas и safe-area для iPhone;
- офлайн-кэш через Service Worker;
- GitHub Actions → GitHub Pages;
- часть оригинальных Unity-ресурсов восстановлена непосредственно из APK и подключена к веб-порту.

## Восстановлено из APK

Из уцелевшего `sharedassets1` удалось извлечь оригинальные текстуры Воджиры, поверхности земли, классического фона, HUD, эффектов, актёров/транспорта, боссов и оригинальные экраны обучения. В текущую веб-сборку уже встроены оригинальные `Wojira_Tex`, `Background_Classic_Tex` и `GroundStrip_Tex`.

По оригинальным экранам обучения восстановлены механики метаболизма/здоровья, комбо, подземного ускорения, плевка, удара-метеорита и EMP с зарядкой фиолетовыми кристаллами.

Подробности и ограничения конкретной копии APK: [`RECOVERY.md`](RECOVERY.md).

## Запуск локально
```bash
python3 -m http.server 8080
```
Откройте `http://localhost:8080`.

## GitHub Pages
Workflow `.github/workflows/deploy-pages.yml` запускается на каждый push в `main`. В Settings → Pages источник должен быть **GitHub Actions**.

## Telegram Mini App
После публикации GitHub Pages укажите HTTPS URL приложения в BotFather (Mini App / Menu Button). Приложение автоматически определяет Telegram WebView и вызывает `ready()` / `expand()`.

## iOS
Откройте опубликованный URL в Safari → «Поделиться» → «На экран Домой». PWA запускается как отдельное полноэкранное приложение.

## Важно по исходному APK

Это старая Unity 4.2.0f4-сборка. В переданной копии начало оригинального ZIP-потока частично перезаписано другим APK, поэтому отсутствуют исходные байты `Assembly-CSharp.dll`, `level0`, `mainData` и первого сегмента `sharedassets0`. Из-за этого точную C#-логику и сцену нельзя восстановить из этой конкретной копии байт-в-байт. Если появится более полный APK той же версии, его можно использовать как донор для недостающих сегментов и существенно приблизить веб-порт к оригиналу.
