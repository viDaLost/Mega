# Мега Червь — Web / iOS PWA / Telegram Mini App

Русскоязычная браузерная реконструкция Super Mega Worm 2.0.0 по данным оригинального Unity APK. Игра работает как статическое HTML5 Canvas-приложение и поддерживает Safari/iPhone, установку как PWA и Telegram Mini App.

## Активная сборка

Публичная версия использует **`app-v17.js`** — обычный несжатый JavaScript без runtime-распаковки, `eval` и `DecompressionStream`.

Перед каждым деплоем GitHub Actions выполняет `node --check` для runtime, Service Worker и файлов кампаний, а также проверяет ссылки на них в `index.html`. Это предотвращает публикацию синтаксически повреждённого bundle.

## Кампании

- **Standard Adventure** — уровни 1–25 обычной прогрессии; BonusMode на 5/10/15/20; финальная запись Level 25. Level 26 сохранён только в исходных восстановленных данных и не входит в обычную прогрессию.
- **Xmas2 / Santa** — уровни 1–17; BonusMode на 5/10/15; Level 16 — CutsceneBoss-переход; Level 17 — Giant Robot.

Таблицы уровней восстановлены из Unity plist. Переключатель кампании меняет активный массив уровней без перезагрузки страницы.

## Что восстановлено

- реальные параметры движения `SMW_Player` из `Assembly-CSharp.dll`;
- оригинальные таблицы уровней и состав противников;
- EMP, огненный плевок и удар-метеорит;
- базовые типы техники, авиации и боссов;
- оригинальные текстуры Воджиры, фона, земли, техники и boss-atlas;
- восстановленные браузерно-совместимые звуки;
- русский интерфейс, touch-кнопки, iPhone safe-area, PWA и Telegram WebApp SDK.

## Исправление неработающего экрана

Предыдущий `app-v16.js` содержал повреждённый base64/gzip payload. `atob()`/распаковка завершались ошибкой до регистрации обработчиков кнопок, поэтому HTML отображался, но экран не реагировал на нажатия. `v16` удалён. `v17` собран заново из рабочего несжатого runtime и проверяется CI перед публикацией.

Service Worker использует новый cache namespace, поэтому повреждённая версия вытесняется после обновления приложения.

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Telegram Mini App

В BotFather используйте URL `https://vidalost.github.io/Mega/`.

## iOS

Откройте сайт в Safari → «Поделиться» → «На экран Домой». После обновления старой установленной версии полностью закройте PWA и откройте её снова, чтобы новый Service Worker получил управление.

Подробности восстановления находятся в [`RECOVERY.md`](RECOVERY.md).
